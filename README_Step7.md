# Step 7 PeMS Model Experiments

Repository: https://github.com/rarra21/Springboard

Dataset: `sample_pems_data_small.csv`

Raw data URL used by the notebook:
https://raw.githubusercontent.com/rarra21/Springboard/main/sample_pems_data_small.csv

## Files

- `Step7_PeMS_Model_Experiments_EXECUTED.ipynb`: executed notebook with model experiments
- `sample_pems_data_small.csv`: PeMS sample data
- `step7_model_results.csv`: model comparison results
- `step7_model_results_with_ensemble.csv`: model comparison including ensemble
- `step7_cv_train_validation_gap.csv`: train-validation gap analysis
- `best_model_predictions.csv`: final model predictions
- `step7_figures/`: output graphs
- `step7_models/`: saved fitted models

## How to Run

Open the notebook in Google Colab, Jupyter Notebook, or VS Code and run all cells. The notebook first tries to load the local dataset. If it is not available locally, it loads the raw GitHub dataset URL.
